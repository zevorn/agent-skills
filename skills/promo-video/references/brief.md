# 需求讨论与创意简报

每支片子从一次需求讨论开始。讨论的结果写成创意简报，再由简报决定叙事结构、画面风格、动效语言和配乐；
分镜和代码都在简报确认之后开始。

## 讨论方式

- 先读用户已经给出的材料（产品介绍、实验记录、参考视频、品牌资料），只问材料里没有的内容。
- 分轮提问，每轮 3–5 个问题，按下面的顺序推进；用户已经回答的内容不再重复询问。
- 用户给出参考视频或网页时，先看完全部内容，再说明打算借鉴的具体元素（节奏、版式、转场、配色、字幕方式）。
- 用户的回答比较笼统时，给出两到三个具体的示例让用户挑选：例如三种开场方式的截帧、两种转场组合的联系表（来自 `assets/motion/gallery.html`）。
- 每轮结束时复述理解到的目标与约束，请用户确认或修正。

## 要问清楚的内容

| 主题 | 问题 |
| --- | --- |
| 目的 | 这支片子要让观众记住什么？看完之后希望观众做什么（试用、联系、转发、加入）？ |
| 观众 | 谁会看：工程师、管理者、投资方、普通观众？他们已经知道多少？ |
| 平台 | 在哪里播放：B 站、官网、发布会大屏、展会循环播放？竖屏还是横屏？ |
| 长度与节奏 | 期望时长；是否需要短版本；整体快节奏还是从容讲解？ |
| 内容 | 必须出现的事实、数字、画面；不能出现或需要回避的内容；对比对象与公平性要求 |
| 证据 | 每个关键说法的数据来源；哪些产品描述需要用户确认 |
| 品牌 | 标志、主色、字体、口号；有没有必须遵守的品牌规范 |
| 风格 | 喜欢与不喜欢的参考；希望给人的感觉（严谨、科技、温暖、热血、轻松） |
| 声音 | 旁白还是纯字幕；配乐风格；是否需要音效 |
| 交付 | 分辨率（1080p、4K）、封面、字幕文件、发布文案、截止时间 |

## 创意简报

简报写在项目目录的 `brief.md`，用户确认后再开始分镜：

```markdown
# 创意简报

- 一句话目标：
- 观众与播放场景：
- 时长与节奏：
- 核心信息（按重要性排列）：
- 必须出现的事实与数据来源：
- 对比对象与测试条件：
- 品牌约束：
- 风格关键词（3–5 个）与参考：
- 动效性格：precise / energetic / calm / playful，或自定义的缓动组合
- 转场词汇（3–5 种，每种的用途）：
- 声音：旁白 / 字幕；配乐速度与调性；音效重点
- 交付清单：
- 待确认事项：
```

## 从简报到动效

- **风格关键词 → 动效性格**：严谨、工程感对应 `precise`（快入慢停、少回弹）；发布会、热血对应 `energetic`（回弹与爆发）；
  叙事、人物对应 `calm`（正弦缓动、长停留）；面向大众、轻松对应 `playful`（弹性与反弹）。性格决定缓动的基调，具体效果按每个场景的内容选择。
- **核心信息 → 画面重点**：最重要的数字用最强的揭示方式（数字滚动加圈注、闪白切入），次要信息用克制的方式出现。
- **观众 → 信息密度**：工程师观众可以保留条件标签与脚注；普通观众把条件压缩成一句话，细节放进简介。
- **平台 → 节奏**：信息流平台前 5 秒给出最强画面；大屏与展会循环播放注意首尾衔接。

## 确认节点

1. 简报确认后，提交分镜表与动效计划（见 [动效与转场](motion.md)）。
2. 动效计划确认后，渲染 3–5 张风格帧（每个部分一张）与一段 10–20 秒的样片，确认风格后再完成全片。
3. 全片初版交付后，按用户反馈修改；修改后重新运行质检。
